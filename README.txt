CAMPUS — демонстрационный студенческий портал

Как открыть:
1. Распакуйте архив в любую папку.
2. Откройте папку CAMPUS через VS Code.
3. Откройте index.html в браузере или запустите через расширение Live Server.

Файлы:
- index.html — структура сайта
- style.css — оформление
- script.js — интерактивность и демонстрационные данные

Возможности:
- Главная страница и сводка
- Расписание по дням недели
- Список заданий с добавлением и отметкой выполнения
- Электронная зачётка с оценками по предметам IT-колледжа
- Посещаемость
- Электронная библиотека с материалами по HTML/CSS, Python, SQL, сетям, операционным системам, алгоритмизации, информационной безопасности, математике, IT English и UX/UI
- Открытие и чтение каждого учебного материала
- Поиск по библиотеке
- Демонстрационный групповой чат
- Центр уведомлений и отметка прочитанного
- Редактирование профиля

Важно:
Это фронтенд-прототип. Материалы, оценки и остальные данные демонстрационные и пока хранятся только в оперативной памяти страницы. Для настоящих аккаунтов, общего чата, реального расписания и сохранения данных нужна серверная часть и база данных.
